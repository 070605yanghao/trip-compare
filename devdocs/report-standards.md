# 报告渲染规范（report-standards.md）

> 改 `report.py` / `compare.py` 的展示逻辑前必读。偏离需人批准并记入 decisions.md。

## 四态标记

| 状态 | 标记 | 文案规则 |
|---|---|---|
| included | ✓ | 按维度细分：明确包含 / 明确赠送 / 明确提供 / 明确说明 |
| excluded | ✗ | 需自理维度按条目细分：明确需自理 / 明确需自费 / 明确需自理/自费（关键词判定，全自费才写自费） |
| ambiguous | ~ | 表述模糊或自相矛盾，需人工确认 |
| unknown | ? | 灰色「未提及」，文案必须含「不等于不包含」的图例说明 |

## 独家 vs 差异

- **独家**：仅当本品明确包含 **且** 其他所有产品明确不包含（双向证据）。证据不足（对方未提及）不标独家。
- **差异**：仅用于属性维度（天数/团型/用车/住宿/路线/人群）取值不同，不代表独有或更优。服务维度不用「差异」。

## 展示与依据一致

- 列表维度展示条数 = 依据条数 = `MAX_SHOW`（4），超出时依据区补「… 共 N 条原文依据」。
- 截断必须补「…」，且不能在未闭合括号中间切断（`_clip_ev` 栈式检查）。
- 摘要区（sumbox）的住宿摘要、核心差异摘要截断同样补「…」，底层数据不截断。

## 文案

- 赠送项目的转发提示：「共 N 项，详情见「X」维度」，N 必须来自实际数据。
- 同一维度内的条目展示不带公共段头前缀（「费用包含：车费」 → 「车费」）。

## 视觉

- 蓝白主色（header 深蓝渐变 #0b2a6b→#1557e8），状态色：绿=包含、红=不含、橙=模糊、灰=未提及。
- 单文件 HTML，内嵌样式，零外部依赖，移动端可读（表格横向滚动）。

## 改完必做

Chrome 无头截图核对实际渲染：`chrome --headless=new --screenshot=out.png --window-size=1400,2600 file:///…/报告.html`，截图与文本 dump 都要看。
